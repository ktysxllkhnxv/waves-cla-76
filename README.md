## Overview

Waves CLA-76 models the UREI 1176 FET peak limiter in two versions—Blacky (Rev D) and Bluey (Rev E)—calibrated by legendary mixer Chris Lord-Alge for authentic 1176 tone.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves CLA-76** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Two Models** | Blacky (Rev D) and Bluey (Rev E) with distinct tonal characters |
| **All-Buttons Mode** | All four ratio buttons in simultaneously for extreme hyper compression |
| **Fast Attack** | FET-based sub-millisecond attack for transient limiting and punch |
| **CLA Calibration** | Calibrated to Chris Lord-Alge's personal 1176 unit settings |
